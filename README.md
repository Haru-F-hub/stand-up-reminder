# 起身一下 · Stand-up Reminder

一个专注「久坐提醒」与「喝水记录」的轻量级单页网页。

打开就能用，不需要安装、不需要登录、没有后端服务。所有数据只保存在你自己的浏览器里。

## 功能特性

- **久坐提醒**：可设置专注时长（10–90 分钟），时间到后弹出休息对话框，并随机推荐一个微活动。
- **微活动库**：内置 8 个不占地方、随手可做的小动作（肩颈放松、脚踝画圈、远眺呼吸等）。
- **每日目标**：记录今天起身活动的次数，带进度条与达标提示。
- **饮水追踪**：以 200ml 一杯为单位记录饮水，目标 2L（10 杯），支持撤销一杯。
- **喝水提醒**：按设定间隔（30–120 分钟）提醒喝水，可在提醒弹窗中一键记录。
- **系统通知与提示音**：授权后可推送系统通知；提醒时播放简短提示音（可关闭）。
- **自动保存**：计时状态、今日进度、喝水记录与提醒设置都会保存在浏览器本地，刷新或重新打开页面不会丢失。
- **响应式布局**：手机与桌面浏览器均可使用。

## 快速开始

### 方式一：直接打开（最简单）

下载或克隆本仓库后，双击 `index.html`，用浏览器打开即可。

```bash
git clone git@github.com:Haru-F-hub/stand-up-reminder.git
cd stand-up-reminder
```

> 直接用 `file://` 打开大部分功能可用。若系统通知等特性表现异常，请改用方式二。

### 方式二：本地静态服务器（推荐）

在项目目录下启动任意静态文件服务器，例如：

```bash
# Python 3
python3 -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8080>。

## 使用说明

1. 点击右上角 **◎** 按钮，允许浏览器发送系统通知（可选）。
2. 在「提醒设置」中选择专注时长、休息时长、每日目标和喝水提醒间隔。
3. 点击 **开始这一轮** 开始专注计时。
4. 计时结束后会自动弹出休息对话框，跟着提示做一个微活动，再点击 **我已活动，继续专注**。
5. 每次喝水后点击 **+ 喝水 200ml** 记录，或直接在喝水提醒弹窗里点击 **记一杯**。

> 设置中的「10 秒（测试）」「1 分钟（测试）」选项用于快速验证提醒是否正常工作。

## 数据存储与隐私

- 所有数据均通过浏览器 `localStorage` 保存在**本地设备**，不会上传到任何服务器。
- 关闭或清除浏览器数据会同时清除记录。
- 项目不收集任何个人信息，也不依赖任何第三方分析服务。

主要使用的存储键：

| 键名 | 用途 |
| --- | --- |
| `stand-up-today` | 当日起身活动次数 |
| `stand-up-active-timer` | 当前计时状态（用于刷新后恢复） |
| `water-today` | 当日饮水量 |
| `water-reminder-settings` | 喝水提醒开关与间隔 |
| `water-reminder-today` | 下一次喝水提醒时间 |

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无打包工具）
- 浏览器 Web API：`localStorage`、`Notification`、`AudioContext`、`navigator.vibrate`

## 浏览器支持

建议使用最新版本的 Chrome、Edge、Firefox 或 Safari。

- 系统通知依赖浏览器的 `Notification` 权限，部分浏览器在非 HTTPS 或非 localhost 环境下会限制该功能。
- 震动提醒仅在支持的移动浏览器上生效。

## 部署到 GitHub Pages

1. 进入仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支与 `/`（根目录）后保存。
4. 稍等片刻，页面即可通过 `https://<用户名>.github.io/stand-up-reminder/` 访问。

## 常见问题

**提醒没有弹出系统通知？**
请先点击页面右上角的 **◎** 按钮授权，并确认浏览器/系统未屏蔽该站点的通知。

**刷新后计时还在继续吗？**
在「正在专注」或「已暂停」状态下刷新，计时状态会被恢复；休息对话框不会自动恢复。

**记录会同步到其他设备吗？**
不会。数据仅保存在当前浏览器的本地存储中。
